# Agent Router 路线图

2026-09-14：用户授权启动下一轮开发，并纳入墨小汐接入需求。当前定版为[方案v1](V1.md)，实现版本v0.4.1；保持下方原四项计划，增加独立宿主任务接口。实施与验证状态见[VALIDATION](VALIDATION.md)。

顺序：定版Router与墨小汐合同 → 模型目录/联网证据/评测与桌面入口 → 持久宿主接口和执行监督 → 回归及分层验收。墨小汐手机三项痛点等用户回来，不作为本轮前置。

## v0.3.0之后保留的原计划

以下为后续研究方向，未包含在 v0.3.0 的现有功能中。

## 模型清单不再预设

- 允许用户输入供应商、接口地址、模型 ID、认证方式以及可用工具。
- 探索通过供应商接口和公开资料自动发现可用模型。
- 区分模型的通用能力与具体执行环境的工具能力、成本、额度和限制。

## 预研支持网页搜索

- 在需求分析阶段搜索官方文档、实现方案及最新资料。
- 记录实际查阅的来源、时间与结论，区分事实、推断和未验证假设。
- 让用户能审阅联网研究如何影响最终执行 Prompt。

## 根据权威评测动态选型

- 查找模型在权威评测网站/排行榜中的对应条目、具体位置与测试成绩。
- 核对模型版本、评测任务类型与更新时间，避免把名称接近但不同版本的模型混为一谈。
- 综合任务需求、相关评测、工具环境、价格、额度、时限及本地执行经验，形成可解释的推荐。
- 评测数据缺失或不适用时明确显示不确定性，不用单一总排名代替工程判断。

## 保留审阅发布流程

继续采用“需求 → 预研 → 可编辑方案 → 审阅发布”的方式。模型发现、联网检索和动态评估服务于方案，不跳过用户对实际执行内容的审阅。
